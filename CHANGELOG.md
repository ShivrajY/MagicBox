# Changelog

All notable changes to MagicBox will be documented here. The project is in
public preview and does not yet promise stable API compatibility.

## [Unreleased]

- Added the .NET 10 universal-scraper solution with Core, Browser, CLI, and
  Tests projects.
- Added schema-validated YAML adapters for Google, Yahoo, Bing, AOL,
  DuckDuckGo, and Brave search results.
- Added asynchronous extraction, pagination, retries, safety checks, bounded
  scheduling, encrypted secrets, optional browser rendering, and streaming
  JSONL/CSV sinks.
- Added deterministic offline fixtures and cross-platform CI.
